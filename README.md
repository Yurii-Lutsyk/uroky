# Практичні сторінки до уроків

Інтерактивні сторінки, які учні відкривають із телефона за посиланням.
Кожна сторінка — один файл, усе працює в браузері, нічого встановлювати
не треба.

## Що тут можна, а чого не можна

**Можна:** умови завдань, тести, редактори, приклади, дані з підручника.

**НЕ можна:** нічого про конкретних учнів. Ні імен, ні прізвищ, ні оцінок,
ні відвідуваності, ні нотаток про те, хто чого не зрозумів. Репозиторій
публічний, бо інакше GitHub Pages не віддасть сторінку.

Усе, що стосується учнів, живе в окремому проєкті `School` і сюди
не потрапляє ніколи.

## Як додати урок

1. Покласти файл у папку класу: `9-klas/назва.html`.
2. Додати рядок у `index.html`.
3. `git push` — за хвилину сторінка оновиться.
